# EGAnetLab Bibliography

**Complete APA 7th edition reference list of every source cited by
EGAnetLab.**

Inside jamovi, each method-backed table cites its own sources in jamovi's
native numbered format (`jamovi/00refs.yaml` + `refs:`). jamovi's reference
renderer fixes that format and only shows it under `Table` results; it is a
constraint of jamovi's interface, not a choice of the module. Where the
report text names a source inline (e.g. "Golino et al., 2020"), it says
"see references" instead of a bracket number, because jamovi assigns the
number at render time. This page is the authoritative APA 7th edition list
(CODE_STYLE.md §21): every key in `jamovi/00refs.yaml` appears here, and
every source cited in the report text appears in `jamovi/00refs.yaml`.

# Bibliografía de EGAnetLab

EGAnetLab.**

Dentro de jamovi, cada tabla respaldada por un método cita sus propias
fuentes en el formato numerado nativo de jamovi (`jamovi/00refs.yaml` +
`refs:`). El visor de referencias de jamovi fija ese formato y solo lo
muestra bajo resultados de tipo `Table`; es una restricción de la interfaz de

número entre corchetes, porque jamovi asigna ese número al mostrar el
resultado. Esta página es la lista autorizada en APA 7.ª edición (CODE_STYLE.md
