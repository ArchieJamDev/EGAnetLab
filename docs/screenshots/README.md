# Screenshots

Images used by the main README. They are real jamovi screenshots of
EGAnetLab (Spanish report, English menu).

| File | Content |
|---|---|
| `demo.gif` | Slideshow of the eleven source screenshots (`ega1.png` to `ega11.png`): network, riEGA, bootstrap, CFA, hierarchical EGA, centrality and Dynamic EGA. 1000 × 540 px, 1.8 s for the first frame and 2.2 s for the rest, endless loop, as in AssumptionsLab |
| `ega-network.png` | EGA network plot with the EGAnet Lab menu (source `ega1.png`) |
| `ega-wording.png` | Random-intercept EGA (riEGA) section (source `ega2.png`) |
| `bootega-stability.png` | bootEGA item stability plot (source `ega3.png`) |
| `hierarchical.png` | Hierarchical EGA plot (source `ega6.png`) |
| `centrality.png` | Centrality stability plot (source `ega10.png`) |
| `dynamic-ega.png` | Dynamic EGA population network (source `ega11.png`) |

To rebuild `demo.gif`, crop the jamovi title bar and ribbon (top 154 px) from
each source screenshot, fit it on a white 1000 × 540 canvas, and save the
frames in order as an animated GIF.
